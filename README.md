
# zbomb - by ItzzEIias

A simple zbomb for termux and ish shell made in python


## Installation

Install zbomb on termux

```bash
  pkg update && pkg upgrade -y && pkg install git python2 -y
  git clone https://github.com/itzzEIias/zbomb
  cd zbomb
  python zbomb.py
```
    
Install zbomb on ISH shell

```bash
  apk update && apk upgrade
  apk add git && apk add python2
  git clone https://github.com/ItzzEIias/zbomb
  cd zbomb
  python2 zbomb.py
```
